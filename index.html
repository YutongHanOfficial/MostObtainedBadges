Roblox — Most Obtained Badges Tracker

Fetches `awardedCount` for badges from Roblox's badges API (via RoProxy). Paste badge lines or add IDs manually.

Auto-refresh every min
Input format (CSV lines): Game, Badge Name, BadgeID
Proxy: badges.roproxy.com — required to avoid CORS from Roblox APIs.
Quick note: the BadgeID is the numeric id used by Roblox. You can get it from the badge page URL on the Roblox web: e.g. https://www.roblox.com/badges/123456789/... . If you don't have IDs yet, paste the CSV without IDs and fill them later. See below for usage details.
